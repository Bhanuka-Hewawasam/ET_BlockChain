1.  Dashboard (ප්‍රධාන පිටුව) මෙය පද්ධතියේ ප්‍රධාන තොරතුරු පෙන්වන පිටුවයි. වාර්තා
    සංඛ්‍යාව හෝ තත්ත්ව සාරාංශ වැනි දේ පෙන්විය හැකියි. ඒවා සැබෑ දත්ත මත ගණනය වනවාද,
    Demo දත්තද යන්න ක්‍රියාත්මක කිරීම අනුව වෙනස් විය හැකියි.

2.  Upload Document (ලේඛනය උඩුගත කිරීම) පරිශීලකයා ගොනුව තෝරා උඩුගත කරයි. පද්ධතිය
    ගොනුව කියවා SHA-256 Hash අගයක් සකස් කර Reference ID එකක් ලබා දෙයි. ඉන්පසු
    වාර්තාව Prototype එකේ සුරැකීමේ ක්‍රමයට අනුව ගබඩා කරයි. සටහන: Local Storage
    භාවිත කරන විට වාර්තාව සුරැකෙන්නේ එම බ්‍රවුසරයේ පමණි. Browser data මකා දැමුවහොත්
    වාර්තා නැති විය හැකියි.

3.  Verify Document (ලේඛනය පරීක්ෂා කිරීම) පරිශීලකයා Reference ID එක ඇතුළත් කර
    අදාළ ගොනුව තෝරා “Verify now” බොත්තම ඔබයි. පද්ධතිය: • Reference ID එකට
    අදාළ වාර්තාව සොයයි. • උඩුගත කළ ගොනුවේ SHA-256 Hash එක ගණනය කරයි. • එය
    වාර්තාවේ සුරැකි Hash අගය සමඟ සසඳයි.

ප්‍රතිඵල: • Hash අගයන් ගැළපේ නම් — “File fingerprint matched” ලෙස පෙන්වයි. •
Hash අගයන් නොගැළපේ නම් — ගොනුව ලියාපදිංචි ගොනුවට නොගැළපෙන බව පෙන්විය යුතුය. •
Reference ID එකට වාර්තාවක් නොමැති නම් — “Document not recognised” වැනි පණිවිඩයක්
පෙන්වයි. • විශ්වාසදායක මුල් Hash අගයක් නොමැති Demo වාර්තාවක් නම්, එය සත්‍ය බවට තීරණයක්
නොදිය යුතුය.

4.  Verification History (පරීක්ෂණ ඉතිහාසය) කලින් සිදු කළ පරීක්ෂණ පිළිබඳ තොරතුරු බැලීමට
    භාවිත කරන පිටුවයි. පෙන්වන තොරතුරු සහ ඒවා කොපමණ කාලයක් පවතිනවාද යන්න දත්ත සුරැකීමේ
    ක්‍රමය මත රඳා පවතී.

5.  Reference ID එකේ කාර්යය Reference ID එක යනු පද්ධතියේ ලේඛන වාර්තාවක් සොයා
    ගැනීමට භාවිත කරන හඳුනාගැනීමේ අංකයකි. එය පමණක් තිබීමෙන් ලේඛනය සත්‍ය බව ඔප්පු නොවේ.
    ගොනුවේ Hash අගයත් සසඳා බැලිය යුතුය.

6.  QR Reference කොටස අතුරුමුහුණතේ QR ආකාරයේ රූපයක් පෙන්විය හැකියි. එය සැබෑ QR
    කේතයක් ලෙස ක්‍රියාත්මක කර නැත්නම්, Scan කිරීමෙන් ලේඛනය තහවුරු නොවේ. එවැනි අවස්ථාවක
    එය Demo රූපයක් බව පැහැදිලිව සඳහන් කළ යුතුය.

7.  Ledger Status / Blockchain ගැන අතුරුමුහුණතේ “Simulation active” හෝ
    “Hash-linked audit trail” වැනි වචන පෙනුණත්, සැබෑ Blockchain ජාලයක් හෝ
    distributed ledger එකක් සම්බන්ධ කර නොමැති නම්, එය සැබෑ Blockchain ක්‍රියාත්මක
    කිරීමක් නොවේ. දැනට මෙය Blockchain සංකල්පයට අදාළ අදහසක් පෙන්වන Prototype
    එකක් ලෙස විස්තර කිරීම නිවැරදියි.

8.  සර්ට Website flow එක පැහැදිලි කරන කෙටි ක්‍රමය “පළමුව පරිශීලකයා ලේඛනය Upload
    කරනවා. පද්ධතිය එයට SHA-256 Hash එකක් සකස් කර Reference ID එකක් ලබා දෙනවා.
    පසුව Verify පිටුවේ එම ID එක සහ ලේඛනය නැවත ලබා දුන් විට, පද්ධතිය අලුතින් ගණනය
    කරන Hash එක සුරැකි Hash එක සමඟ සසඳනවා. ඒ අනුව ගැළපීම, නොගැළපීම හෝ වාර්තාව
    නොමැති බව පෙන්වනවා.”
